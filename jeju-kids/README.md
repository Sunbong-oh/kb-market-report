# 제주 아이 행사 알리미

4살 아이가 신청할 만한 제주 프로그램(도서관 책 읽어주기·공연·체험·체육·영어·미술·요리)과 행사의 **신청 날짜를 놓치지 않게** 텔레그램으로 알려 주고, 모은 내용을 사이트로 보여 줍니다.

## 알림 받는 때
- 신청 시작 **3일 전**, **전날 저녁 7시**, **당일 아침 6시**, **시작 1시간 전**
- 신청 마감 전날
- 기관 누리집·뉴스에 유아·가족 대상 **새 공고가 뜨면** 바로 (아침 6시, 저녁 8시 확인)
- 밤 10시~아침 6시에는 조용히 (단, 1시간 안에 시작하는 신청은 알림)
- **월요일 아침**: 앞으로 2주 신청 일정 요약

## 인스타그램 게시물 넣기 (텔레그램 받은편지함)
인스타그램은 로그인 없이 자동으로 긁으면 금방 막혀서, 보다가 괜찮은 게시물을 **아이 행사 봇에게 보내는** 방식이에요.
- 게시물 **공유 → 텔레그램 → 아이 행사 봇** (링크만 와도 공개 게시물이면 글·대표 사진을 읽어요)
- 포스터 **캡처 사진** (여러 장 한 번에 OK), 또는 모집 글 **복사·붙여넣기**
- **맘카페(제주맘·어멍 카페 등)** 글은 로그인해야 보여서 링크만으론 못 읽어요. 본문을 복사하거나 캡처해서 보내 주세요 (링크도 함께 보내면 알림에 바로가기로 붙어요)
- 15분 안에 "✅ 저장했어요 · 신청 시작 10/27(화) 09:00 → 알림 등록" 답장이 와요
- `/list` 다가오는 신청 · `/del 번호` 잘못 읽은 일정 지우기

### 받은편지함 설정 (한 번만)
1. 텔레그램 @BotFather → `/newbot` 으로 **아이 행사 전용 봇**을 새로 만들고 토큰을 받아요.
   (장마감 리포트 봇은 노트북 서버가 메시지를 받고 있어서 같이 쓰면 서로 메시지를 빼앗아요.)
2. 새 봇과 대화를 열고 `/start` 를 보내요.
3. 저장소 Settings → Secrets and variables → Actions 에 추가:
   - `KIDS_TELEGRAM_BOT_TOKEN` = 새 봇 토큰 (필수)
   - `ANTHROPIC_API_KEY` = 포스터 캡처를 읽을 Claude API 키 (선택, 없으면 글 속 날짜만 찾음. 게시물 1건에 약 20~30원)
   - `KIDS_ALLOWED_CHAT_IDS` = 배우자 등 함께 쓸 사람의 chat id (선택. 그 사람이 봇에게 말을 걸면 봇이 번호를 알려 줘요)
4. 그 뒤로는 알림도 새 봇이 보내요. 리포트 대화방과 분리돼서 보기 편해요.

## 파일
| 파일 | 내용 |
| --- | --- |
| `events.json` | 직접 관리하는 일정. 신청 날짜를 알게 되면 여기에 `apply_start`를 넣으면 알림이 걸립니다 |
| `sources.json` | 매일 확인하는 기관 누리집과 뉴스 검색어 |
| `kids.py` | 수집·알림·사이트 생성 |
| `inbox.py` | 텔레그램 받은편지함 (인스타 링크·캡처·글 → 일정) |
| `template.html` | 사이트 화면 |
| `state/` | 이미 본 공고·보낸 알림 기록 (Actions가 자동 갱신) |
| `site/` | 생성된 사이트 (GitHub Pages로 배포) |

## 처음 설정 (한 번만)
1. 이 브랜치를 `main`에 합칩니다. 예약 실행은 기본 브랜치에서만 돕니다.
2. 텔레그램 비밀값은 장마감 리포트에 쓰는 `TELEGRAM_BOT_TOKEN`·`TELEGRAM_CHAT_ID`를 그대로 씁니다.
   다른 대화방(예: 배우자와 함께 쓰는 그룹)으로 받고 싶으면 Secrets에 `KIDS_TELEGRAM_CHAT_ID`를 추가하세요.
3. 사이트: 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면
   `https://sunbong-oh.github.io/kb-market-report/` 에 열립니다.
4. Actions 탭 → "제주 아이 행사 알리미" → Run workflow로 첫 실행을 해 보세요.
