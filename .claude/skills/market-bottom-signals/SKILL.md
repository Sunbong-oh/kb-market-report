# 증시 저점 판별 (풋콜비율 · VIX 다이버전스 · 자금시장 필터)

폭락장의 바닥은 가격만 봐서는 알 수 없다. 바닥은 **매도 연료(공포에 질린 매도, 급한 헤지, 강제 청산)가 바닥날 때** 나온다. 이 스킬은 그 연료를 세 가지로 잰다.

1. **풋콜비율(CNN 방식, 5일 평균):** 개인·헤지 수요의 공포
2. **VIX 장중 고점:** 시장 전체가 사는 보험 가격
3. **단기자금시장 스프레드(금융CP − T-bill):** 공포가 금융 시스템까지 번졌는지(가짜 바닥 필터)

## 바닥의 두 가지 유형

**① 투매형(capitulation):** 한 번에 공포가 폭발하고 끝나는 바닥이다. 풋콜 5일 평균이 1.0 이상으로 치솟고, VIX가 급등한 뒤 장중 고점에서 15% 이상 꺾인다.
예: 2025.4.8(풋콜 1.04, VIX 장중 60.1 → 다음 날 33.6)

**② 다이버전스형(divergence):** 1차 폭락 뒤 가격이 다시 밀려 **전저점을 깨는데**, VIX 장중 고점과 풋콜 고점은 **1차 때보다 낮은** 바닥이다. 가격은 더 빠졌는데 겁은 줄었다는 뜻이다. 팔 사람은 이미 팔았고 헤지도 걸려 있어 매도 연료가 고갈된 상태다.
예: 2011.10.3 S&P(VIX 48.0 → 46.9, 풋콜 0.93 → 0.81), 2011.9.26 코스피(1,684 → 1,644로 전저점 이탈, VIX 43.9, 풋콜 0.73), 2009.3.9(VIX 81.5 → 52.0, 풋콜 1.03 → 0.84)

투매형 신호 뒤에는 **재시험**이 올 수 있다. 2022년 6월 풋콜 1.10 투매는 자금시장이 정상이었는데도 최종 바닥이 아니었고, 10월 다이버전스(VIX 35.1 → 34.5, 풋콜 1.10 → 0.94)가 진짜 바닥이었다. 2008년 11월 투매 뒤 2009년 3월 다이버전스도 같은 순서다. 그래서 투매 신호가 나오면 분할로 대응하고, 그 투매의 VIX·풋콜 고점을 다음 다이버전스의 기준점으로 삼는다.

두 유형 모두 **자금시장 필터를 통과해야** 믿는다. 2008년 3월(투매형)과 7월(다이버전스형)은 신호가 나왔지만 금융CP 스프레드가 1%p를 넘어 있었고, 결국 리먼 사태로 무너졌다. 신호가 같아도 금융 시스템이 막혀 있으면 바닥이 아니다.

## 절차

### 1. 데이터를 직접 계산한다

기억이나 검색 결과의 숫자 대신 번들 스크립트로 원자료를 계산한다. 풋콜과 VIX는 하루만 달라도 판정이 바뀐다.

```bash
python <skill-dir>/scripts/bottom_signals.py --index ^GSPC --start 2026-10-01 --ref-low-date 2026-11-05
python <skill-dir>/scripts/bottom_signals.py --index ^KS11 --start 2026-10-01 --ref-low-date 2026-11-06
```

- `--index`: 가격 기준 지수(^GSPC, ^IXIC, ^KS11, ^KQ11 등). 풋콜과 VIX는 미국 데이터를 쓴다.
- `--ref-low-date`: **1차 폭락 저점일**. 다이버전스 비교의 기준점이다. 모르면 생략하면 구간 앞쪽 절반의 최저 종가를 자동으로 고른다. 이 기준점이 판정을 좌우하므로 사용자와 맞춰 본다.
- `--json out.json`: 차트나 리포트에 쓸 일별 데이터를 저장한다.
- 데이터 출처: Cboe 풋콜 아카이브(2006~2019)와 일일 통계(2019.10~), Yahoo 일봉, FRED(하이일드 OAS, Baa−10년, 금융CP, T-bill). 접근이 막힌 사이트를 헤더 위조로 우회하지 않는다. CNN dataviz API는 막혀 있으므로 쓰지 않는다.

### 2. 신호를 읽는다

스크립트 출력의 `[신호]` 블록이다.

| 키 | 뜻 | 판정 |
|---|---|---|
| `capitulation` | 투매형 | `met: true`면 풋콜 5일 평균 1.0 이상 이후 VIX가 장중 고점에서 15% 이상 꺾였다 |
| `divergence` | 다이버전스형 | `met: true`면 전저점 이탈 + VIX 장중 고점 하락 + 풋콜 5일 평균 고점 하락 |
| `funding_filter` | 자금시장 필터(핵심) | `ok`(0.5%p 미만)일 때만 위 신호를 믿는다. `fail`(1.0%p 이상)이면 신호를 버린다 |
| `credit_filter` | 하이일드·Baa(참고) | `stressed`라도 거부권은 없다. 2011년 바닥은 하이일드 약 7%에서 나왔다 |

### 3. 아직 신호가 없을 때는 '기준선'을 알려 준다

가장 쓸모 있는 답은 "다음에 무엇이 나오면 바닥인가"다. 현재 기준점(1차 폭락의 VIX 장중 고점과 풋콜 5일 평균 고점)을 숫자로 제시한다.

- **투매형까지 남은 거리:** 현재 풋콜 5일 평균과 1.0의 차이
- **다이버전스 조건:** "가격이 X를 깰 때 VIX 장중 고점이 Y 미만, 풋콜 5일 평균이 Z 미만이면 다이버전스"
- **공포 확산 국면:** 가격 신저점과 함께 VIX·풋콜도 더 높아지고 있으면 바닥이 아니다. 기준점을 새 고점으로 갱신해서 다음 재시험을 기다린다.

### 4. 한국 시장에 적용할 때

- 코스피는 미국 밤 사이 급락이 다음 날 갭으로 반영돼 신저점이 '강제'되는 날이 많다. 그날 코스피 저점은 **같은 날 밤 미국장의 VIX 장중 고점**과 함께 본다.
- 시장 간 다이버전스도 강한 신호다. 2008년 11월 미국은 신저점을 냈지만 코스피는 10월 저점(892)을 지켰다. 2008년 코스피는 미국보다 4.5개월 먼저 바닥을 쳤다.
- 한국 고유 수급(신용융자 반대매매, 외국인 순매도 지속)은 바닥을 며칠 늦출 수 있다. 신호가 나와도 분할로 대응하라고 권한다.
- **외국인 풋옵션 매도(국내 보조 신호, 사용자 경험칙):** 외국인이 코스피200 풋옵션을 **하루 200억원 이상 순매도**하기 시작하면 시장이 바닥을 준비할 가능성이 높아진다. 큰손이 "여기 아래로는 잘 안 간다"에 돈을 걸고 비싸진 풋 프리미엄을 팔기 시작했다는 뜻이다. 폭락 뒤 변동성이 치솟아 풋값이 비쌀 때 나오는 매도라 공포 정점 통과와 같은 방향의 신호다.
  - 데이터: kb-market-report 장마감 기록 `archive/YYYY-MM-DD/본문_장마감수급.txt`의 `- 풋옵션: 외국인 … / 기관 … / 개인 …` 줄(억원, KB증권 Open API, 2026-10-01부터). `--index ^KS11`이면 공개 저장소(github.com/Sunbong-oh/kb-market-report)에서 자동으로 받아 오므로 어느 계정·PC에서도 된다. 로컬 클론이 있으면 `--kr-flow-dir <archive 폴더>`, 끄려면 `--kr-flow-dir none`. 결과는 `kr_foreign_put_sell` 신호(기준 바꾸기 `--kr-put-sell 200`).
  - 쓰는 법: 단독 매수 신호가 아니라 미국 쪽 신호(투매형·다이버전스형)와 **겹칠 때** 무게를 둔다. 둘이 같은 주에 나오면 바닥 가능성이 크게 높아진 것으로 설명한다.
  - 한계: 장기 일별 이력(KRX)을 확보하지 못해 과거 검증을 하지 않은 경험칙이다. 2026년 10~11월 하락 구간(36거래일)에는 외국인 풋 순매도 최대가 47억(10/15)으로 한 번도 200억에 닿지 않았다. 사용자가 HTS에서 과거 일별 자료를 내려받아 주면 검증을 보탠다.

## 출력 형식

```
## 저점 판별 (기준일 YYYY-MM-DD, 지수 OOO)
판정: [투매형 바닥 후보 / 다이버전스형 바닥 후보 / 아직 신호 없음(공포 확산 중) / 신호 있으나 자금시장 경색으로 불신]

| 항목 | 1차 폭락 (날짜) | 현재/신저점 (날짜) | 판정 |
| 지수 종가 | | | 전저점 이탈 여부 |
| VIX 장중 고점 | | | 낮아졌나 |
| 풋콜 5일 평균(주식+ETP, CNN 근사) | | | 1.0 이상 / 낮아졌나 |
| 금융CP−T-bill (5일) | | | ok/caution/fail |
| 하이일드 OAS / Baa−10년 | | | 참고 |

다음 기준선: (위 3번의 숫자)
비슷한 과거 사례: (references/historical_cases.md에서 가장 가까운 1~2개)
```

투자 판단은 사용자 몫이다. 신호는 확률을 높이는 근거일 뿐 보장이 아니라는 점과 분할 대응을 함께 말한다.

## 주의할 점

- **CNN 원값과 차이:** CNN은 어떤 풋콜비율인지 밝히지 않는다. 차트 역산값과 가장 가까운 것이 Cboe '주식+ETP' 5일 평균이다(2026.11 오차 0.01~0.04). 2012년 6월 전 Cboe '주식' 풋콜에는 ETP가 포함돼 있어 같은 정의로 이어진다. CNN 지수는 2012년에 나와 그 전 값은 재구성치다.
- **원값보다 상대 수준:** 0DTE 확산 등으로 풋콜 평균 수준이 시대마다 다르다. 스크립트의 `z5`(직전 1년 대비 표준편차)도 함께 본다. 2025.4는 +4.6σ, 2008.10~11은 +2.4~2.8σ였다.
- **종가와 장중값을 섞지 않는다:** VIX는 장중 고점끼리, 지수는 종가끼리 비교한다(스크립트 기준).
- **표본이 적다:** 성공·실패 사례는 각각 손에 꼽을 정도다. 신호는 "바닥일 확률이 높아졌다"는 뜻으로 전달한다.
- **정책 예외:** 2020.3.23은 자금시장 스프레드가 1.12%p로 'fail'이었지만, 연준이 무제한 유동성 장치를 발표한 날이라 바닥이 됐다. 중앙은행 긴급 개입이 있으면 필터를 다시 판단한다.

과거 사례의 날짜별 수치는 `references/historical_cases.md`에 있다. 사용자가 과거와 비교해 달라고 하거나, 판정을 설명할 비슷한 사례가 필요할 때 읽는다.
